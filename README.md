# Super Play

**Super Play is an independently branded fork of [CloudStream](https://github.com/recloudstream/cloudstream).** It aims to preserve the upstream media-player and extension functionality while developing under the Super Play name.

> **Important:** Super Play does not provide video sources by default. You must add compatible extensions or repositories yourself. Only use sources and extensions you are legally entitled to access.

## Platforms

The upstream project includes Android phone and Android TV support, plus a desktop application. Build availability and release packages for this fork depend on successful builds and testing.

## Upstream project and documentation

- [CloudStream source repository](https://github.com/recloudstream/cloudstream)
- [CloudStream documentation](https://recloudstream.github.io/csdocs/)
- [Extension development guide](https://recloudstream.github.io/csdocs/devs/gettingstarted/)

## Important notice

Super Play is a community fork and is not the official CloudStream project. Upstream features, extension compatibility, and platform support may change as the fork is maintained. No media catalog or hosting service is included by default.
